# Estilo IA

Estilo IA es una plataforma web orientada a la compra, publicación y recomendación de prendas de vestir mediante una experiencia moderna e intuitiva.  
El proyecto cuenta con un backend desarrollado en **Spring Boot** y un frontend desarrollado en **React**.

## Descripción del proyecto

Al ingresar a la plataforma, el usuario se encuentra con un panel informativo sobre la aplicación, junto con las opciones para **iniciar sesión** o **crear una cuenta**.

Una vez autenticado, el usuario accede al panel principal, donde encontrará una cabecera con diferentes secciones de navegación:

- Prendas para hombre
- Prendas para mujer
- Prendas unisex
- Recomendación con IA
- Perfil del usuario

Desde la sección de perfil, el usuario podrá:

- Publicar sus propias prendas
- Visualizar las prendas que ha vendido
- Gestionar información relacionada a su cuenta

Actualmente, la pasarela de pago está pendiente de integración, por lo que en esta versión se trabajará como una **demo funcional**.
